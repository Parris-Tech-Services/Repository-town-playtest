# Sylvie Phonics Adventure Roadmap

This roadmap organizes future ideas from `suggestions.md` and the EYLF feature map. The core EYLF implementation task list is complete.

## Priority 1: Product Maintainability

- Consider splitting the single `index.html` into source modules if the app continues growing.
- Keep `docs/eylf-curriculum-feature-map.md` synchronized when adding modes.
- Add a basic smoke-test checklist for each game mode.
- Keep optional content validation current with `scripts/validate-content.mjs`.

## Priority 2: Phonics Depth

- Improve multisensory letter tracing with better stroke/progress detection.
- Expand sound scavenger hunt content.
- Add richer blending animations for Sound Blocks.
- Expand environmental print examples with parent-reviewed content.

## Priority 3: Listening, Songs, and Movement

- Add more interactive sound songs.
- Add repeat and next-sound controls for song sets.
- Expand Sound Jump with more active choices and keyboard/touch variants.
- Add additional co-play prompts for transfer into the home environment.

## Priority 4: Parent and Educator Support

- Improve session summaries and review exports.
- Add clearer parent notes for speech synthesis limitations.
- Provide optional printable practice cards.
- Add more family-facing reflection prompts.

## Content Caution

Do not bulk-generate culturally specific or Aboriginal and Torres Strait Islander content. Use the optional content bundle only for material that has appropriate human review.
