# Multi-Layer Zoom Game

This project combines three zoom layers into a single game experience:

1. **World Map Layer** - Large-scale map for traveling and exploration
2. **Town Map Layer** - Zoom into towns with ASCII-style maps
3. **Encounter Layer** - Detailed scenes for combat and encounters

## Architecture Overview

- State management to handle current zoom level and map data
- Data models for world map, town maps, and encounters
- Transition system to move seamlessly between layers
- UI components tailored for each zoom level
