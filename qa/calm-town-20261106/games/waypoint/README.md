# 🧭 Waypoint — Personal Decision Navigator

A small, grounded tool for moving from overwhelm to **one clear next step**. It walks you
through five honest questions, then saves the decision as a card you can revisit. It never
decides for you and never pretends certainty.

## The five steps

1. What are you deciding or avoiding?
2. What matters most here?
3. What are the real options?
4. What is the smallest reversible next step?
5. What would wisdom, kindness, and courage look like?

## Features

- Five-step guided flow with progress bar and back/next.
- Tag each decision: `work`, `family`, `health`, `money`, `project`, `faith`.
- Decisions saved to **localStorage** as revisitable cards.
- **Export** all decisions as JSON or Markdown.
- Clear empty state until you save your first decision.

## Run

Static, single file:

```bash
start index.html        # Windows — or
python -m http.server 8000
```
