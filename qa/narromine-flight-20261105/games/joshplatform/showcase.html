🧩 JoshPlatform

A lightweight mini app platform / experiment runtime — a single shell for launching small prototypes, reusable UI patterns, and personal tools.

What this platform is for

Instead of a new repo per idea, JoshPlatform is one tidy place to spin up and document small experiments. Each "app" is a self-contained module with a status badge, so it's clear what's finished, what's a prototype, and what's just an idea. The richer interactive version runs on React + Vite (npm run build:client); this page is the static front door.
